## Design Context

### Users
Mac power users (developers, designers, writers, support folks) who capture the screen dozens of
times a day, usually mid-task: copying an error message out of a video call, grabbing a UI bug for a
ticket, pinning a reference next to the code they're writing. They come from CleanShot X and are
frustrated by lag. The tool must disappear: hotkey, result, back to work.

### Brand Personality
**Quiet, exact, instant.**
- Quiet: never more chrome than the moment needs; neutral surfaces, one accent.
- Exact: pixel-true captures, honest sizes, aligned to a 4pt grid, numbers in tabular figures.
- Instant: every interaction answers within a frame; motion confirms, it never delays.

Emotional goal: the calm confidence of a well-made instrument. Not playful, not flashy.

### Aesthetic Direction
- Design language: shadcn/ui (new-york, neutral) ported faithfully to SwiftUI: hairline borders,
  soft-neutral fills, near-black primary, 10pt radius, restrained shadows.
- Typeface: Plus Jakarta Sans (owner's explicit choice) for all UI and annotation text.
- Color: OKLCH-derived neutrals tinted very slightly toward the brand hue (262, the blue of the
  app icon). The brand blue is reserved for selection, focus, and "this is live" signals.
- Theme: follows the system. A utility used all day in every app must match whatever the user runs.
  Capture overlays are always neutral and dim so the user's own pixels stay the hero.
- Anti-references: glassy "AI" gradients, neon-on-dark, oversized rounded icon tiles, playful
  bounces, toolbar clutter.

### Design Principles
1. **The screenshot is the hero.** Chrome recedes; overlays dim, never tint, the user's content.
2. **Zero-wait feedback.** Freeze the screen, crop in memory, show results before the disk finishes.
3. **One accent, used sparingly.** Brand blue only marks selection, focus, and the active tool.
4. **Progressive disclosure.** Quick Access shows a thumbnail; hovering reveals actions; the editor
   reveals tool options only for the active tool.
5. **Keyboard first.** Every primary action has a shortcut, shown with a Kbd where it's learnable.
